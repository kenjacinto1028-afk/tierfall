# Tierfall assistant instructions

Before working on any Tierfall task in any chat, read [GITHUB_SYNC.md](GITHUB_SYNC.md). This GitHub repository is the shared project reference. Commit tested, approved project changes here when the GitHub connector permits; don't overwrite newer commits.
