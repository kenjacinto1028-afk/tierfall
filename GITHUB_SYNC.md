# Tierfall — GitHub sync rules (all project chats)

**Canonical repository:** https://github.com/kenjacinto1028-afk/tierfall

This policy applies to ALL Tierfall project chats: narrative writing, code, UI, worldbuilding, portraits, character design, documentation, tests and playable builds.

1. **Check existing state first.** Review `TASK_STATE.md` if available, relevant files, repository commits, and `git status` when working in a local clone. Resume incomplete work instead of restarting.
2. **Keep GitHub updated.** After each verified and user-approved change, update the appropriate GitHub files and commit checkpoints. The user has authorized ordinary Tierfall sync commits across chats; do not require a new yes for every routine commit. Preserve existing work and don't overwrite newer changes.
3. **Sync all applicable outputs.** Include docs, code, art, tests, portable builds and manifests where tools permit. If any item cannot be uploaded, say which one and provide a downloadable alternative; never claim success without remote verification.
4. **Protect the player's experience.** Do not reveal future plot, character secrets, twists, relationships' hidden outcomes, or endings in chat, readmes, changelogs or commit messages. Player-facing release notes must be spoiler-free.
5. **PUBLIC repo restriction.** Until this repo is confirmed PRIVATE, only upload player-safe material. Do not upload files such as `STORY_OUTLINE.md`, `STORY_SECRETS.md`, protected character arcs or unreleased narrative scripts. Folder names do not make files secret.
6. **Portrait approval.** Approved faces and art directions are references. Never replace live in-game portrait assets until the user explicitly approves that change.
7. **Check tests and remote state.** Test game behavior where possible. Read back or inspect successful GitHub commits. Record commits and unfinished sync items in checkpoints.
8. **Do not auto-release.** Routine repository commits are approved; making the repo public/private, enabling Pages, publishing releases or distributing story spoilers still require explicit user direction.

## Suggested ChatGPT Project instructions

For every chat in the Tierfall Project, use `https://github.com/kenjacinto1028-afk/tierfall` as the shared source of truth. Read `GITHUB_SYNC.md` at the beginning of work. Commit verified approved changes when the GitHub connector is available, including writing, visuals, code and docs. Protect spoilers while the repo is public; report anything not synced. Don't replace game portraits without permission.
