## Important: repository visibility

**This repository is currently PUBLIC.** Unreleased story outlines, character secrets, hidden plot twists and endings must NOT be uploaded while public. Switch to **Private** in repository Settings → General → Danger Zone → Change repository visibility before syncing protected narrative files.

## Source status

This is a public-safe snapshot. The HTML is playable; the complete original TypeScript source/build/test chain has not been recovered and should not be described as present. The 27 approved neutral character portraits are installed in `game/assets/portraits/` and referenced by the Chapter 1 HTML when the game is hosted with its asset folder. Offline HTML without accompanying image assets still works using built-in fallback portraits. Additional expression variants remain drafts and are not installed.

## Working rule

All Tierfall chats should use this repository as their shared source of truth, following [GITHUB_SYNC.md](GITHUB_SYNC.md). Game changes require tests and spoiler-free update notes.
